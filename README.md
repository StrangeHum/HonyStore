# HonyStore

**HonyStore** — учебный pet-проект интернет-магазина, вдохновлённый функциональностью крупных e-commerce платформ, таких как Ozon.

Проект разрабатывается на **C# / .NET** с применением принципов **Clean Architecture** и **Domain-Driven Design (DDD)**.

Основная цель проекта — получить практический опыт проектирования архитектуры приложения, построения доменной модели и реализации бизнес-логики с учётом принципов поддерживаемости и расширяемости кода.

## Текущий статус разработки

**В разработке**

На данный момент основное внимание уделяется разработке доменного слоя.

Реализовано:

- **Доменные сущности (Entity)** — `Product` и `Order`.
- **Базовый класс Entity** — общая абстракция для доменных сущностей.
- **Value Objects** — `ProductPrice` для инкапсуляции логики валидации цены.
- **Фабричные методы (Factory Methods)** — контролируемое создание доменных сущностей.
- **Позиции заказа (Order Items)** — возможность добавлять несколько товаров и несколько экземпляров одного товара в заказ.
- **Обработка ошибок** — использование `CSharpFunctionalExtensions` и типа `Result`.
- **Модульное тестирование** — проверка доменной логики с помощью `xUnit.v3`.

## Доменная модель

На текущем этапе разработка сосредоточена на двух основных сущностях.

### Product (Товар)

Представляет товар интернет-магазина.

- Содержит название, описание и цену.
- Использует `ProductPrice` в качестве Value Object для инкапсуляции валидации цены.
- Создаётся через фабричный метод.
- Поддерживает изменение цены с предварительной валидацией нового значения.

### Order (Заказ)

Представляет заказ покупателя.

- Содержит коллекцию позиций заказа `OrderItem`.
- Поддерживает добавление нескольких товаров, включая несколько экземпляров одного товара.
- Сохраняет цену товара на момент добавления в заказ.
- Хранит статус заказа и рассчитывает его общую стоимость.

## Цели проекта

- Получить практический опыт разработки приложения с использованием Clean Architecture и DDD.
- Применять принципы SOLID и паттерны проектирования на практике.
- Развивать навыки проектирования доменных моделей и реализации бизнес-логики.
- Освоить подходы к модульному тестированию и обработке ошибок.
- Постепенно расширять функциональность интернет-магазина.
